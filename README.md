# Reserves Meter (CTR Nitro-Fueled, OCTR PC port)

A game patch by Onur: shows your boost reserves as a bar and in seconds, in every HUD style.
For the USA game, CUSA13795 version 1.21, on the [OCTR port](https://github.com/Ryu7w7/OCTR-NitroFueled-PC).

Work in progress.

Idea from tomtotom's "CNK Drift Gauge + Reserves Meter"; this patch is written from scratch and
uses none of its code or files.
